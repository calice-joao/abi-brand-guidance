# AB InBev Brand Guidance for Codex

A Codex skill for applying AB InBev's corporate visual identity to presentations and interfaces. It includes the guidance, reference PDF, and selected brand assets.

## Download

Download the `abi-brand-guidance` skill folder from the approved internal location shared by your team. Keep the folder name and its contents unchanged.

## Install in Codex (Windows)

1. Close Codex.
2. Copy the entire `abi-brand-guidance` folder to:

   `%USERPROFILE%\.codex\skills\abi-brand-guidance`

   Create the `skills` folder if it does not exist. The installed folder must contain `SKILL.md`, `assets`, and `references`.
3. Reopen Codex. If the skill does not appear, restart Codex once more.

## Use

Ask Codex for the work and name the skill, for example:

- “Use the AB InBev brand guidance to create a corporate presentation about …”
- “Use the AB InBev brand guidance to design this interface …”
- “Review this presentation for AB InBev corporate brand consistency.”

Creation is the default. Codex reviews existing material when you request a review. The skill covers AB InBev's corporate identity; it does not replace product-brand guidance.

## Update

When the brand guidance changes, download the latest approved package from the internal source and replace your installed `abi-brand-guidance` folder. The bundled reference is version 1.1, last updated January 2022; confirm the current guidance with the ABI Creative Hub before relying on it for new work.
